# growth/inbox — owner → model handoff

Drop raw material here; the weekly task consumes it and moves it.

## For a field note (CONTENT-FIELD-NOTE)
Create a folder `inbox/<yyyy-mm-dd>-<short-job-name>/` containing:
- 3–6 photos (JPG/HEIC, any size; before / during / after is ideal)
- `facts.md` — plain bullets, no polish needed:
  - city (and neighborhood/landmark if ok to mention)
  - species (best guess is fine)
  - the problem / why we were called
  - what we did (and what we declined to do, and why)
  - what we found or flagged
  - size/equipment/crew, how long it took
  - anything the customer said we can quote (first name only)
Photos of customers' house numbers / faces → we crop or skip.

## For the About page (CONTENT-ABOUT)
`inbox/about-facts.md`: founding story, team roles, equipment/fleet, standards you want named,
insurance/COI line, 4–6 photos.

## For cost pages / pricing changes
`inbox/pricing-<date>.md`: the ranges you actually quote this season. The model never invents ranges.

## Output from the model (`inbox/out/`)
Off-site packs the model writes for you to execute: `nap-fix-<date>.md`, `gbp-<month>.md`,
`directories-batch-<n>.md`, `reviews-sop.md`, `lists-outreach.md`. Tick them off; the model
re-checks listings two weeks later.
